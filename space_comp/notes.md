| Data structure                                                | Typical space                                                      | Why                                                                                       |
| ------------------------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| A few variables (min, max, counters)                          | O(1)O(1)O(1)                                                       | Fixed number of scalars, doesn't grow with input                                          |
| Two pointers (indices only)                                   | O(1)O(1)O(1)                                                       | Just integer indices, no extra storage                                                    |
| Hashmap / hashset                                             | O(n)O(n)O(n)                                                       | Stores up to n keys/values                                                                |
| Array/list used as extra storage (e.g. prefix sums, DP array) | O(n)O(n)O(n)                                                       | One slot per input element                                                                |
| 2D DP table                                                   | O(n×m)O(n \\times m)O(n×m)                                         | Grid sized by both dimensions                                                             |
| Stack (monotonic stack, DFS call stack, valid parentheses)    | O(n)O(n)O(n) worst case                                            | Can hold up to n elements before popping                                                  |
| Queue (BFS)                                                   | O(n)O(n)O(n) worst case                                            | Can hold up to n nodes at widest level                                                    |
| Heap / priority queue                                         | O(n)O(n)O(n) worst case, often O(k)O(k)O(k) if you only keep top-K | Stores elements currently in the heap                                                     |
| Recursion (tree/graph DFS)                                    | O(h)O(h)O(h) where h = height/depth                                | Call stack grows with recursion depth, not total nodes                                    |
| Union-Find (parent + rank arrays)                             | O(n)O(n)O(n)                                                       | One entry per node                                                                        |
| Sorting in-place (e.g. Python's Timsort on a list)            | O(n)O(n)O(n) or O(log⁡n)O(\\log n)O(logn)                          | Depends on language/algorithm; Python's sort uses O(n)O(n)O(n) auxiliary space worst case |
